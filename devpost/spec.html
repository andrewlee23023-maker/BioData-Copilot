BioData Copilot — Technical Blueprint

Full-Stack Architecture, AI/Python Boundary & Component Specification

System Architecture & Execution Pipeline

⚡ Frontend Tier

  • React 18 + Vite: Instant HMR, fast compilation, lightweight JSX components.
  • Tailwind CSS: Rapid scientific dark theme styling without CSS bloat.
  • Plotly.js: Interactive scientific graphs with tooltips, box plots, and zoom capabilities.

🐍 Backend Tier

  • FastAPI (Python): High performance, automatic OpenAPI documentation, clean async endpoints.
  • Pandas & NumPy: Reliable CSV parsing, data grouping, and aggregation.
  • SciPy (`scipy.stats`): Deterministic hypothesis testing (`f_oneway`, `ttest_ind`, `mannwhitneyu`).
  • Gemini 2.5 Flash: Ultra-fast intent structuring and concise scientific interpretation.

🛡️ The Strict Separation of Concerns

To ensure mathematical reproducibility and scientific trustworthiness:

LLM Responsibilities

  • Understand natural language questions
  • Map terms to detected dataset columns
  • Select appropriate test (ANOVA vs t-test vs trend)
  • Synthesize readable biological interpretation

Python Responsibilities

  • Filter and validate tabular data
  • Calculate sample sizes (n) and group means
  • Execute exact statistical tests and p-values
  • Build the interactive Plotly chart specification

⚠️ Failure Modes & Graceful Fallbacks

  • No Gemini API Key: Backend automatically switches to a deterministic keyword-matching fallback planner so the app runs 100% locally with zero external dependencies.
  • Unsupported Question: Returns a friendly error explaining: "This demo currently supports descriptive analyses, group comparisons, correlations, and basic experimental trends."
  • Sample size < 2: Skips hypothesis testing and returns descriptive metrics only with an alert noting insufficient degrees of freedom.
