BioData Copilot — Product Specification

Interactive Screen Walkthrough, Behavioral Guardrails & Acceptance Criteria

1. Interactive Screen & Behavior Walkthrough

Screen A — Landing & Dataset Ingestion

First Touchpoint

Designed for immediate zero-friction onboarding. Researcher either drags their CSV or clicks 1-click synthetic demo.

[ HEADER: BioData Copilot • Ask questions about your experimental data ]
┌────────────────────────────────────────────────────────────────────────┐
│ [ ⬆ Drag & Drop Experimental CSV or Browse ] │
│ or click: [ 🧪 Try Example Dataset (Cell Viability Assay) ] │
└────────────────────────────────────────────────────────────────────────┘
✓ Dataset loaded: 127 observations | 4 treatments | 3 doses | 3 replicates
Detected Columns: [sample_id] [cell_line] [treatment] [dose] [timepoint] [replicate] [viability]

Acceptance Criteria:

  • Clicking "Try Example Dataset" immediately mounts the 127-row dataset with zero page reload.
  • Compact metadata badges show observations, treatments, doses, and detected data types.
  • Corrupt or non-CSV file uploads trigger an inline error badge without breaking state.

Screen B — Question Formulation

Intent Capture

Empowers natural language query with fast clickable sample chips to accelerate demo walkthroughs.

[ SECTION: Ask a Scientific Question ]
┌────────────────────────────────────────────────────────────────────────┐
│ "Which treatment produced the highest cell viability compared with │
│ control?" │
└────────────────────────────────────────────────────────────────────────┘
Suggested: [Which treatment has highest viability?] [Is Drug B different from Control?] [Viability vs Dose?]

[ 🚀 Analyze → ]

Acceptance Criteria:

  • Clicking any prompt chip instantly populates the query input.
  • "Analyze →" button is enabled only when a dataset is loaded and question contains text.

Screen C — Transparent Analysis Activity

Trust Engine

Never fake completion states. Reflects real backend progress as the AI validates schema and Python calculates.

[ LIVE ACTIVITY STREAM ]
✓ Inspecting dataset columns and types
✓ Identifying experimental groups (treatment vs viability)
✓ Checking sample sizes (n=32 per treatment)
→ Executing One-way ANOVA & Tukey post-hoc in Python
○ Generating Plotly interactive chart
○ Grounding scientific explanation in verified numbers

Acceptance Criteria:

  • Each step reflects genuine server pipeline transitions.
  • Clear visual spinner on active step with smooth checkmark resolution.

Screen D — Verified Results & Plotly Visualization

Outcome

Publication-grade visual clarity. All metrics originate directly from Python SciPy output.

[ RESULT SUMMARY CARDS ]
Top Performer: Drug B  |  Mean Viability: 94.8%  |  Delta vs Control: +3.6 pp  |  Test: ANOVA p = 0.014

[ 📊 Interactive Plotly Box Plot / Bar Chart with Error Bars ]

Scientific Interpretation:
"Drug B demonstrated the highest mean viability (94.8% ± 2.1% SD) among all tested treatments, showing a statistically significant increase compared with the vehicle control (p = 0.014, one-way ANOVA)."

Notice: Synthetic demonstration data — not real experimental results. This describes observed experiment and does not establish causality.

Acceptance Criteria:

  • Every displayed numeric value matches the backend Python output to the decimal.
  • Interactive Plotly chart features hover tooltips with sample count and mean values.
  • Synthetic disclaimer and non-causality statement are persistently visible.

🛡️ Scientific Guardrails

  • Sample size check: Flags warnings if n < 3 per group.
  • Missing value detection: Reports null counts before test execution.
  • Zero hallucination constraint: LLM prompt explicitly receives computed JSON dict and is forbidden from computing new metrics.
  • Non-causality disclosure: Automatically attached to all comparative summaries.

⚠️ Graceful Edge Case Handling

  • Unsupported questions: Friendly refusal banner with list of supported analysis modes.
  • Missing columns: Clear message if user asks about a column not present in the dataset.
  • Invalid CSV format: Clean parsing failure notification without app crash.
