BioData Copilot

Plain-English questions on experimental datasets → reproducible Python statistical analyses & visual explanations.

🔬 The Unique Kernel: "LLM reasons; Python computes"

The AI translates researcher intent into a concrete statistical analysis plan, but never invents numbers. Python (Pandas, SciPy, NumPy) performs 100% of data aggregation, hypothesis testing, and p-value computation. Every metric displayed in the UI is mathematically verifiable.

Interactive Architecture & Workflow Flow

👤 Target User & Core Loop

Who: Biology & biotech lab researchers working with plate-reader, viability, or dose-response assays.

Problem: Spending hours writing ad-hoc Pandas/matplotlib scripts just to answer simple comparative questions.

Solution: Upload CSV → Ask in natural language → Get verified statistics and publication-grade plots in seconds.

✅ Definition of Done (Hackathon MVP)

  • Upload CSV or click 1-click synthetic demo dataset
  • Inspect dataset columns, types, rows, and groups
  • Ask supported scientific questions with suggested prompts
  • Transparent progress indicators for each analysis step
  • Verified statistical results (ANOVA, t-test, Mann-Whitney)
  • Interactive Plotly visualization with error bars/distribution
  • Grounded interpretation with synthetic disclaimer & no causal overclaims

🎯 Scope Boundaries

  • Dataset Inspection: Row/col counts, numeric vs. categorical detection, missing value scan. Now
  • Statistical Engines: Two-sample t-test, Mann–Whitney U, One-way ANOVA, descriptive summary (mean, SD, n). Now
  • Visualizations: Box plot, bar chart with error bars, scatter/dose-response, line plots via Plotly. Now
  • AI Planner & Explainer: Structured tool calling to validate analysis plan before execution; strictly grounded scientific summary. Now
  • Synthetic Demo Dataset: Pre-packaged cell viability experiment with treatment, dose, timepoint, replicate, viability. Now
  • Longitudinal modeling: Multi-timepoint time course trajectory fitting. Later
  • Curve Fitting: Four-parameter logistic (4PL) regression and IC50/EC50 calculation. Later
  • Export Notebooks: Download reproducible Jupyter notebook (.ipynb) or Python script. Later
  • Outlier Detection: Automated Grubbs' test or IQR anomaly filtering. Later
  • User Authentication / Accounts: Zero value for a local demo; adds auth friction. Cut
  • Database Storage: Session-based in-memory processing is faster, lighter, and privacy-preserving. Cut
  • Arbitrary Code Execution: Security and hallucination risk; only predefined, validated tools execute. Cut
  • Multi-Agent Swarms: Slow, non-deterministic, and prone to cascading failure for simple analytical tasks. Cut
  • RAG / Literature Search: Distracts from verifying the user's uploaded experimental numbers. Cut
